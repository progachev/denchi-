# denchi 

**Индикатор заряда Bluetooth-наушников в системном трее Windows.**

Лёгкая утилита на Go, которая читает уровень заряда подключённых наушников и отображает его прямо в области уведомлений панели задач — в виде цифры на иконке.

## Возможности

- Отображение заряда наушников в трее в виде числа (например, `85`)
- Автоматическое обновление раз в минуту
- Подробная информация во всплывающей подсказке: имя устройства и процент заряда
- Пункт меню «Выход»
- Не требует установки — один `.exe` файл

---

## Требования

- **Windows 10 (1809+) или Windows 11** — более ранние версии не передают уровень заряда Bluetooth-устройств через системный стек
- **Go 1.21+** (для сборки из исходников)
- Наушники должны поддерживать профиль **Battery Service (BAS)** и отображать заряд в «Параметры → Bluetooth и устройства». Если Windows не видит заряд — утилита тоже его не получит

> ⚠️ **USB-донглы (2.4 ГГц)** не поддерживаются: Windows не предоставляет доступ к заряду таких устройств. Для них нужен отдельный reverse engineering протокола производителя.

## Установка и сборка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/progachev/denchi-.git
cd denchi

# 2. Загрузите зависимости
go mod tidy

# 3. Соберите без консольного окна
go build -ldflags -H=windowsgui -o denchi.exe .
```

Запустите `denchi.exe`. Иконка появится в трее (возможно, в скрытых значках — перетащите её на панель для постоянного отображения).

## Как это работает

1. **`sanshoku`** — библиотека для чтения данных с HID/Bluetooth-устройств. Через драйвер `all.Drivers()` перечисляет подключённые устройства и ищет те, что умеют сообщать уровень заряда (`battery.Source`).
2. **`getlantern/systray`** — создаёт иконку в системном трее и пункт меню.
3. **`generateBatteryIcon`** — рисует холст 16×16 с числом заряда и кодирует его в PNG, который `systray.SetIcon` принимает на Windows.

---

## Известные ограничения

- **Один устройство за раз**: утилита показывает заряд первого найденного наушника с доступным уровнем. Поддержка нескольких устройств — в планах.
- **Задержка**: опрос раз в минуту. Можно уменьшить `time.Sleep(1 * time.Minute)` в `updateBatteryLoop`, но это увеличит нагрузку на Bluetooth-стек.

---

## Настройка

| Что | Где | Как |
|---|---|---|
| Интервал опроса | `updateBatteryLoop` | `time.Sleep(1 * time.Minute)` |
| Цвет фона иконки | `generateBatteryIcon` | `color.RGBA{40, 40, 40, 255}` |
| Цвет текста | `generateBatteryIcon` | `color.NewUniform(color.White)` |
| Размер иконки | `generateBatteryIcon` | `size := 16` |
